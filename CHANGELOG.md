# Changelog

## 0.1.0

- Canonical, bounded JSONL observations with strict duplicate rejection.
- Exact test/revision/environment grouping and within-run attempt ordering.
- Mixed-outcome evidence, final observed outcomes, and recovered-run counts.
- Attempt-weighted failure frequency and nominal 95% Wilson intervals.
- Observed duration/retry sums with separate missing-duration and missing-attempt counts.
- Deterministic JSON/text CLI, explicit mixed-evidence gate, and library API.
- Synthetic fixtures, edge tests, wheel CI, and four README languages.

No JUnit/Jest adapter or automatic flaky-test diagnosis is included.
